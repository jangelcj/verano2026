# 🌊 Cerdeña · Verano 2026

Web del viaje familiar a Cerdeña (29 jul – 6 ago 2026). Itinerario día a día, hoteles, restaurantes, barco privado y checklist de maleta. Diseñada para consultarse cómodamente desde el móvil.

## Contenido
- **index.html** — toda la web en un solo archivo (sin dependencias salvo Google Fonts vía CDN).

## Cómo publicarla con Vercel
1. Sube este repositorio a GitHub.
2. Entra en [vercel.com](https://vercel.com) y conéctalo con tu cuenta de GitHub.
3. Pulsa **Add New → Project** e importa este repositorio.
4. No hace falta configurar nada (es HTML estático): pulsa **Deploy**.
5. Vercel te dará una URL pública (p. ej. `viaje-cerdena.vercel.app`) que puedes compartir con la familia.

> Como alternativa rápida, también puedes activar **GitHub Pages** (Settings → Pages → Branch: main) y servir el `index.html` directamente.

## Editar el contenido
Todo está dentro de `index.html`. Cada día es un bloque `<article class="day">`. Puedes cambiar textos, horarios, hoteles o restaurantes editando directamente ese archivo.
